# Meal Planner Agent

Personal cooking assistant — an AI meal planning app being built to explore
production LLM patterns (streaming, tool use, RAG, evals) with React + Node + 
Claude API.

🚧 **Status:** v0.1 in progress

**Live:** https://meal-planner-agent-lemon.vercel.app/

## Stack
- Next.js 15 (App Router) + TypeScript
- Anthropic Claude API (streaming)
- Deployed on Vercel

## Progress
- ✅ Streaming Claude API integration
- ⬜ Tool use / agent loop
- ⬜ RAG over personal recipe corpus (Voyage embeddings + pgvector)
- ⬜ Custom eval framework
- ⬜ UI polish
